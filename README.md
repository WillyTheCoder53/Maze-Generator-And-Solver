## Introduction

A 1700-line OOP console-only coding project for my A-level computer science NEA. The maze, grid, generators and solvers were represented as objects. 

Features include:
- Choosing the size of the maze
- Optional maze generation and solving animations
- Displaying the optimal path
- Choosing the animation speed
- Time taken to generate the maze
- Time taken to solve the maze
- Four different generating algorithms to choose from
- Six different solving algorithms to choose from
- A variety of colours 

Generating algorithms: 
- Aldous Broder
- Recursive Backtracking
- Prim's
- Eller's

Solving algorithms:
- Dead-end filling
- Wall Follower (Right-hand rule)
- Breadth-first search
- Depth-first search
- Dijkstra's
- A*
